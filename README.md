# 大富豪オンライン

友達それぞれのスマホのブラウザから遊べるオンライン大富豪。
Cloudflare Workers + Durable Objects で、ルームごとの対戦状態を WebSocket でリアルタイム同期します。

**公開URL … https://daifugo-online.kyn-dev.workers.dev**

このURLを友達に送るだけで参加できます。アプリのインストールもアカウント登録も不要です。

## 遊び方

1. 名前を入れて「部屋を作る」
2. 表示された**4文字の部屋コード**を友達に伝える
3. 友達は同じURLを開き、名前と部屋コードを入れて「部屋に参加する」
4. 人数が3人以上そろったら、ホストが「ゲーム開始」

3〜6人で遊べます。人数が足りないときはホストがCPUを追加できます。
各プレイヤーには自分の手札しか見えません。

## ルール設定

ロビーの「ルール設定を表示」から、**9カテゴリ・全52項目**を切り替えられます。
編集できるのはホストだけで、他の人は閲覧のみ。ゲーム開始後は変更できません。

### プリセット（ワンタップでまとめて設定）

| プリセット | 内容 |
|---|---|
| シンプル | 革命と8切りだけ。初めての人向け |
| 標準（連盟五大ルール） | 革命・8切り・都落ち・スート縛り・スペ3返し＋階段 |
| パーティー | 標準＋11バック・5スキップ・7渡し・9リバース・10捨て・Qボンバー |
| 全部入り | ほぼ全部ON。法令集モード |

### 1. 基本設定

| 項目 | 説明 | 初期値 |
|---|---|---|
| ジョーカー枚数 | 0 / 1 / 2枚 | 2枚 |
| Joker代用 | ペア・階段の不足札の代わりに使える | ON |
| パス制限あり | 一度パスすると場が流れるまで出せない | ON |
| 開始プレイヤー | ♦3 / ♠3 / ♥3 / ♣3 を持つ人 / 前回の大貧民 / ランダム | ♦3を持つ人 |
| 席順 | 毎回シャッフル / 初回のみシャッフル | 毎回シャッフル |

### 2. 革命系

| 項目 | 説明 | 初期値 |
|---|---|---|
| 革命 | 同じ数字を規定枚数出すと強弱が逆転 | ON |
| 革命の成立枚数 | 3 / 4 / 5枚 | 4枚 |
| 階段革命 | 同じスートの連番4枚以上で革命 | ON |
| Joker革命禁止 | Jokerを混ぜた組は革命として認めない | OFF |
| クーデター（999） | 9を3枚出すと革命 | OFF |
| ナナサン革命（777） | 7を3枚出すと革命 | OFF |
| オーメン（666） | 6を3枚で革命。以降の革命を封じる | OFF |
| 超革命 | 5枚以上出すと革命 | OFF |
| 核爆弾 | 6枚以上で革命。以降は革命返し不可 | OFF |

### 3. 数字ごとの特殊効果

| 項目 | 説明 | 初期値 |
|---|---|---|
| 8切り | 8を出すと場が流れ、続けて自分の番 | ON |
| 5スキップ | 出した枚数分、次の人を飛ばす | OFF |
| 6戻し | 場が流れるまで強弱が反転 | OFF |
| 7渡し | 7の枚数分、好きな手札を次の人に渡す | OFF |
| 9リバース | 手番の回転方向が逆になる | OFF |
| 10捨て | 10の枚数分、手札を捨てられる | OFF |
| 11バック（Jバック） | 場が流れるまで強弱が反転 | OFF |
| Qボンバー | 数字を宣言し、全員にその数字を捨てさせる | OFF |
| 12リバース | 手番の回転方向が逆になる | OFF |
| 13スキップ | 出した枚数分、次の人を飛ばす | OFF |
| 救急車（99） | 9を2枚出すと場が流れる | OFF |
| ろくろ首（66） | 6を2枚出すと場が流れる | OFF |
| 砂嵐（333） | 3を3枚出すとどんな場にも出せて場が流れる | OFF |

### 4. Joker・返し技

| 項目 | 説明 | 初期値 |
|---|---|---|
| スペ3返し | Joker単体に♠3を出して場を流せる | ON |
| スペ2返し | 革命・11バック中はJokerに♠2を出せる | OFF |
| 33返し | Joker単体に3を3枚出して流せる | OFF |

### 5. 縛り

| 項目 | 説明 | 初期値 |
|---|---|---|
| スート縛り | 同じスートが連続すると、そのスートしか出せない | ON |
| 縛りの成立回数 | 2回 / 3回 | 2回 |
| 数縛り | 連番が出ると、次も1つ上の数字しか出せない | OFF |
| 色縛り | 同じ色が連続すると、その色しか出せない | OFF |

### 6. 階段

| 項目 | 説明 | 初期値 |
|---|---|---|
| 階段（ストレート） | 同じスートの連番をまとめて出せる | ON |
| 階段の最低枚数 | 3枚から / 4枚から | 3枚から |
| 階段8切り | 8を含む階段でも8切りが発動する | OFF |

### 7. 上がり禁止（反則上がり）

そのカードを最後の一手にすると反則となり、**下位が確定します**。
手は止めずにそのまま上がらせ、順位だけ下げる方式です。
反則者が複数いる場合は、**あとに反則した人ほど下位**になります。

| 項目 | 初期値 |
|---|---|
| 2で上がり禁止 | ON |
| 3で上がり禁止（革命中） | OFF |
| 8切りで上がり禁止 | ON |
| Jokerを含む上がり禁止 | ON |
| ♠3単体での上がり禁止 | OFF |
| Jで上がり禁止（11バック時） | OFF |
| 10で上がり禁止（10捨て時） | OFF |
| 7で上がり禁止（7渡し時） | OFF |
| 革命を起こしての上がり禁止 | OFF |

### 8. 順位・階級

| 項目 | 説明 | 初期値 |
|---|---|---|
| 都落ち | 前回の大富豪が1位を逃すと大貧民に降格 | ON |
| 下剋上 | 大貧民が1位を取ると全員の階級が逆転 | OFF |
| 上がり流し | 誰かが上がると、その場が強制的に流れる | OFF |

### 9. カード交換

2ゲーム目以降、前回の階級に応じてカードを交換します。

| 項目 | 説明 | 初期値 |
|---|---|---|
| カード交換 | 通常交換 / 交換なし | 通常交換 |
| 天変地異 | 下位の手札が弱すぎる場合、上位と全交換 | OFF |
| 独占禁止法 | 大富豪に2やJokerが集中しすぎたら配り直し | OFF |

## その他の機能

- **ナイトモード** … 右上のボタンで切り替え。設定は端末に記憶されます
- **CPU** … 人数が足りないときにホストが追加できます
- **もう一度遊ぶ** … 結果画面から、同じメンバー・同じルールで次のゲームへ

## 制限・既知の弱点

- **CPUの思考は簡易的**です。同じ数字の組み合わせしか使わず、階段やJoker代用は使いません
- 切断・再接続時の復帰は最低限の作りです。同じ名前・同じ端末で入り直せば席に戻れます
- 部屋は Durable Object に永続化されるため、放置しても消えません（不要な部屋は残り続けます）

## 開発

技術的な構成・設計の意図・実装上の注意点は **[CLAUDE.md](./CLAUDE.md)** にまとめています。

### ローカルで動かす

```bash
npx wrangler dev
```

`http://localhost:8787` で確認できます。別タブを複数開けば対戦テストもできます。

開発者向け機能（テストモード・ダミー席）は `http://localhost:8787/?dev=1` のように
`?dev=1` を付けてアクセスした端末にだけ表示されます。`?dev=0` で解除できます。

### デプロイ

GitHub連携（Cloudflare Workers Builds）済みです。`main` ブランチに push すると
自動でビルド・デプロイされます。手動で行う場合のみ：

```bash
npx wrangler deploy
```

### 公開URLについて

URLは `{Worker名}.{アカウントのサブドメイン}.workers.dev` の形で決まります。
アカウントのサブドメインは Cloudflareダッシュボード → Workers & Pages → 「サブドメイン」
から変更できますが、**そのアカウントの全WorkerのURLが変わる**点に注意してください。

独自ドメインを割り当てる場合は、対象Worker → Settings → Domains & Routes から設定します。
